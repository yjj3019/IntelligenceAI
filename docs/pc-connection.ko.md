# 내 PC 연결

HTTP 응답 대기와 별도로 실행 deadline watchdog이 소유 프로세스를 종료합니다.
최종 승인 heartbeat를 기다리는 gate에도 적용하며 응답 뒤 monotonic deadline을
다시 검사한 다음에만 native stdin을 전달합니다. 최종 gate와 실행 중 응답 지연을
각각 합성 회귀 테스트로 검증합니다.

완료 결과 journal을 저장한 뒤 브라우저 취소가 확정되면 같은 binding의 cleanup
보고로 lease를 정리하고 결과를 `CANCELLED`로 기록합니다. 결과 본문은 가져오지
않으며 같은 journal 재전송으로 CLI를 다시 실행하지 않습니다. 다른 내용이나
지난 generation의 업로드는 계속 거부합니다.

원격 usage는 PC가 보고한 입력·출력 토큰만 포함하는 `INPUT_OUTPUT_ONLY`입니다.
캐시·추론 토큰과 측정 시각은 제공되지 않습니다. 누락된 값은 0이 아닌 미확인 값입니다.

private 콘솔에서 프로젝트 소유자가 자기 PC를 등록하고 연결을 승인한다. PC는 서버로
HTTPS 요청만 보내며 DB URL, 브라우저 세션, OIDC 비밀을 받지 않는다. 기존 CLI 로그인은
PC에 그대로 둔다. 웹 화면을 열어도 설치나 실행을 시작하지 않는다.

연결 화면에서 Claude 또는 Codex를 선택하고 일회용 코드를 만든다. 코드는 5분 안에
한 번만 교환하며 브라우저 저장소와 서버 원문 저장을 사용하지 않는다. PC의 전용
클라이언트에 숨김 입력한 뒤, PC에 표시된 장치 ID와 실행 파일·구성 지문을 웹 화면과
비교해 승인한다. 승인 전에는 작업 입력을 받지 못한다. 연결은 소유자·프로젝트·제공자에
한정하며 최대 30일 후 만료된다. 서버에는 토큰과 등록 코드의 해시만 저장한다.

로컬 운영자가 실행 파일과 전용 private 디렉터리를 먼저 정한다. 서버와 브라우저는
argv, 경로, 환경 변수를 지정하지 않는다. 명령과 설정 절차는 [영문 안내](pc-connection.md)에
있다. 새 POSIX 디렉터리·파일은 0700·0600으로 만들며 Windows에서는 디렉터리의 상속
ACL을 운영자가 확인해야 한다. 기존 CLI 로그인이나 결제 설정은 변경하지 않는다.

각 작업에는 후보·증거·정책·대상·generation·만료·payload에 결합된 별도 승인이 필요하다.
로컬 `once` 명령은 한 작업만 받는다. CLI 호출은 최대 1회, 전체 실행은 최대 60초이며
자동 모델 재시도와 background 서비스 설치는 없다. Grok는 호출별 제한이 검증될 때까지
사용하지 않는다. DB에 직접 연결하는 기존 worker와 이 PC 클라이언트는 서로 다른 경로다.

원격 실행의 허가 시점은 서버 `start` API의 원자적 일회성 승인이다. 서버 DB 잠금을
PC stdin 전달까지 유지한다고 보장하지 않는다. 클라이언트는 `start` 요청 전에 attempt
소비 기록을 디스크에 저장하고 실행 직전 권한을 다시 확인한다. 실행 중에는 2초마다
heartbeat를 보내고 거부·통신 실패·제한 초과 시 소유한 로컬 프로세스 종료를 시도한다.
heartbeat lease는 15초다.

`start` 응답 유실, 실행 여부 불명, 만료된 소비 attempt는 `UNKNOWN`으로 남기며 자동
재실행과 복구를 차단한다. 소비 기록을 삭제해 재시작하지 않는다. 저장된 같은 결과만
재전송하며 다른 내용은 충돌로 거부한다. 서버가 artifact ID·프로젝트·작업·고정 이름을
정하고 PC가 보낸 경로는 받지 않는다. 비밀은 private 저장 전에 redaction하며 provider
원문 로그는 서버로 보내거나 저장하지 않는다.

결과·사용량·종료는 `PC_REPORTED / USER_DEVICE_REPORT`로 표시한다. 서버가 검증한
OS 격리, provider 취소, 실제 내부 모델 호출 수, 결제 상태의 증거가 아니다. 실제 호출
수는 미확인으로 남기며 합성 fixture는 `NOTRUN`을 유지한다. 승인한 PC를 신뢰하는
범위에서만 결과를 사용한다.

연결 해제는 **제품에서 승인한 해당 PC의 실행 권한**을 회수한다. 현재 Codex 앱,
SSH 연결, CLI 로그인을 끊는 동작이 아니다. 새 실행은 차단하며 이미 허가된 호출의
중단은 가능한 범위에서 처리한다. 종료 보고 전에는 `CANCEL_REQUESTED`, 확인할 수 없는
실행은 `UNKNOWN`으로 표시한다.

이번 구현은 합성 API·프로세스·UI와 CI 임시 PostgreSQL에서 검증한다. 실제 계정 토큰
발급·저장, 실제 PC 등록, 추가 모델 호출, 운영 HTTPS·OIDC 연결은 수행하지 않았다.
공개 Sites 소개는 읽기 전용 데모다. 운영 배포는 승인된 서버 연결이 필요하며 공식
mcp-ssh 도구가 없어 중단된 상태다. 다른 SSH 경로, 터널, 포트·방화벽 변경으로 우회하지
않았다. component·HTTP 검사를 실제 브라우저 QA로 보고하지 않는다.
